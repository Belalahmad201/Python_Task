# Day 11 - Move Zeroes Problem

## Topic
Efficient Data Movement with Two Pointers

---

## Problem Statement

Move all zeroes in an array to the end while maintaining the relative order of non-zero elements.

### Example

Input:
[0,1,0,3,12]

Output:
[1,3,12,0,0]

---

## Approach Used

Two Pointer Technique

- One pointer traverses the array
- Another pointer keeps track of the position where the next non-zero element should be placed

This helps in:
- Maintaining order
- Avoiding extra space
- Performing in-place operations

---

## Time Complexity

O(n)

Only one traversal is required.

---

## Space Complexity

O(1)

No extra array is used.

---

- Improved optimization skills

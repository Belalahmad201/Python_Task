# Theme Park FastPass Simulator

## Overview

A Python-based queue scheduling simulator that models how a modern theme park manages ride visitors using both standard and VIP FastPass queues.

## Features

* Standard visitor queue management.
* VIP FastPass priority handling.
* FIFO processing for regular visitors.
* Queue status visualization.
* Easy-to-understand scheduling simulation.

## Technologies Used

* Python 3
* collections.deque

## How It Works

1. Visitors enter either the normal queue or VIP queue.
2. VIP visitors receive priority access.
3. The system processes visitors in the following order:

   * VIP Queue First
   * Normal Queue Second
4. Queue status is displayed after operations.

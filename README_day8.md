Objective

The goal of this task is to understand how arrays (lists in Python) work and how they are used to store and process data efficiently.

-- What This Program Does
Creates an array of numbers
Counts how many numbers contain an even number of digits
Displays the final result clearly
Explains real-world usage of arrays
-- Key Concepts Learned
Arrays / Lists
Loops (for)
Conditional Statements (if)
String Conversion
Length Calculation using len()
